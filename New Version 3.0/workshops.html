Prompt Engineering Track

Learn to talk to machines properly.

Weekly hands-on sessions on getting precise, reliable output from large language models — from zero-shot basics to multi-step agent prompting.

Curriculum

Six sessions, in order

Prompt Anatomy

Instructions, context, examples and constraints — the four building blocks of a good prompt.

Zero & Few-Shot

Getting a model to perform a task with no examples, then with a handful.

Chain-of-Thought

Prompting a model to reason step-by-step before answering.

Role & System Prompts

Shaping tone, persona, and boundaries at the system level.

Structured Output

Getting reliable JSON / tables out of a model for downstream code.

Agentic Prompting

Chaining prompts and tools together to complete multi-step tasks.
